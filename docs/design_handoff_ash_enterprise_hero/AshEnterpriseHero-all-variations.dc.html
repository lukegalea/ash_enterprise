defmodule AshEnterprise.Accounts.Team do
  use AshEnterprise.Platform.Resource,
    domain: AshEnterprise.Accounts,
    cdm: [entity: "Team", ownership: :business_owned]

  # From here down: only what is actually specific to Team.
  attributes do
    attribute :name, :string, allow_nil?: false, public?: true
  end
end

Eleven lines. Four of them are the declaration; the rest is the one thing a Team has that nothing else does.

What was derived

Ownership
owner_id (polymorphic user-or-team), owning_business_unit_id, owning_user_id, owning_team_id
Provenance
created_on/by/on_behalf_by, modified_on/by/on_behalf_by, import_sequence_number
Multitenancy
organization_id and the multitenancy block
Authorization
Additive policies — the grant union, applied to every action
Audit
Every action lands in the central event log with actor and transaction id
Concurrency
version_number, wired to Ash optimistic locking
Soft delete
Archival, with cascade to related records
Observability
Telemetry and OpenTelemetry spans on every action
Surfaces
Admin, JSON:API and GraphQL derivation defaults
